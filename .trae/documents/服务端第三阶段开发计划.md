# 服务端第三阶段开发计划

## 阶段目标
实现业务逻辑层的核心功能，包括用户服务完善、好友服务、群组服务、消息服务以及WebSocket连接管理。

## 开发顺序与任务分解

### 1. 实体类设计与实现
- **Friend实体类**：实现好友关系数据模型
- **Group实体类**：实现群组数据模型  
- **GroupMember实体类**：实现群成员关系数据模型
- **Message实体类**：实现消息数据模型

### 2. 数据库表创建
- **friend表**：存储好友关系
- **group表**：存储群组信息
- **group_member表**：存储群成员关系
- **message表**：存储消息记录

### 3. Mapper层实现
- **FriendMapper**：好友关系数据访问接口
- **FriendMapper.xml**：好友关系SQL实现
- **GroupMapper**：群组数据访问接口
- **GroupMapper.xml**：群组SQL实现
- **GroupMemberMapper**：群成员数据访问接口
- **GroupMemberMapper.xml**：群成员SQL实现
- **MessageMapper**：消息数据访问接口
- **MessageMapper.xml**：消息SQL实现

### 4. Service层实现

#### 4.1 好友服务（FriendService）
- 添加好友请求
- 处理好友请求（同意/拒绝）
- 获取好友列表
- 删除好友
- 获取好友请求列表

#### 4.2 群组服务（GroupService）
- 创建群组
- 加入群组
- 退出群组
- 获取群组列表
- 获取群成员列表
- 踢除群成员
- 修改群信息

#### 4.3 消息服务（MessageService）
- 发送单聊消息
- 发送群聊消息
- 获取聊天记录
- 更新消息状态
- 统计未读消息

#### 4.4 WebSocket连接管理完善
- 用户在线状态管理
- 消息推送机制
- 多设备登录处理
- 连接异常处理

### 5. Controller层实现
- **FriendController**：好友相关REST API
- **GroupController**：群组相关REST API
- **MessageController**：消息相关REST API

### 6. WebSocket消息处理
- 实现消息分发逻辑
- 实现在线状态广播
- 实现群消息推送

## 技术要点

1. **事务管理**：使用Spring事务确保数据一致性
2. **Redis缓存**：用于存储在线状态、群成员列表等高频访问数据
3. **WebSocket优化**：实现高效的消息推送机制
4. **性能考虑**：针对群聊等场景进行性能优化
5. **安全考虑**：确保API访问权限控制

## 依赖与工具
- Spring Boot 3.2.0
- Netty 4.1.100
- MyBatis 3.0.3
- Redis 7.2
- MySQL 8.0

## 实现标准
- 代码符合Java开发规范
- 每个Service方法有详细的Javadoc注释
- 实现必要的异常处理
- 考虑并发场景下的线程安全

## 测试要点
- 单元测试：覆盖核心业务逻辑
- 集成测试：验证各服务间的交互
- 性能测试：验证高并发下的系统表现

## 开发优先级
1. 实体类与数据库表设计（基础）
2. 好友服务（核心功能）
3. 消息服务（核心功能）
4. 群组服务（核心功能）
5. WebSocket连接管理完善（性能优化）
