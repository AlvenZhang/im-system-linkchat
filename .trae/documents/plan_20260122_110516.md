# DDD架构项目清理方案

## 1. 项目现状分析

当前项目已经开始了DDD架构转换，但仍然存在一些MVC架构的遗留文件和不符合DDD架构原则的目录结构。

## 2. DDD架构分层回顾

1. **应用层（Application Layer）**：处理用户请求，协调领域对象
2. **领域层（Domain Layer）**：包含核心业务逻辑，实体、值对象、领域服务
3. **基础设施层（Infrastructure Layer）**：处理持久化、通信等技术细节
4. **接口层（Interfaces Layer）**：暴露系统接口，如REST API、WebSocket

## 3. 文件和目录分析

### 3.1 保留的文件和目录

| 目录/文件 | 说明 | DDD分层 |
|----------|------|---------|
| `LinkChatApplication.java` | 主应用类 | 应用入口 |
| `application/` | 应用层，包含命令、查询、服务、DTO | 应用层 |
| `config/` | 配置文件 | 配置层 |
| `domain/` | 领域层，包含用户子域 | 领域层 |
| `infrastructure/` | 基础设施层，包含持久化实现 | 基础设施层 |
| `interfaces/` | 接口层，包含REST API | 接口层 |
| `util/` | 工具类 | 基础设施层 |

### 3.2 需要调整的文件和目录

| 目录/文件 | 说明 | 调整方案 |
|----------|------|---------|
| `entity/` | 数据实体，用于数据库映射 | 迁移到 `infrastructure/persistence/entity/` |
| `mapper/` | MyBatis映射器 | 迁移到 `infrastructure/persistence/mapper/` |
| `netty/` | Netty通信模块 | 迁移到 `infrastructure/netty/` |

### 3.3 缺少的文件和目录

| 目录/文件 | 说明 | DDD分层 |
|----------|------|---------|
| `domain/friend/` | 好友子域实现 | 领域层 |
| `domain/group/` | 群组子域实现 | 领域层 |
| `domain/message/` | 消息子域实现 | 领域层 |
| `infrastructure/persistence/repository/` | 其他仓储实现 | 基础设施层 |

## 4. 清理和调整步骤

### 4.1 第一步：创建缺失的基础设施层目录

```bash
mkdir -p src/main/java/com/linkchat/infrastructure/persistence/entity
mkdir -p src/main/java/com/linkchat/infrastructure/persistence/mapper
```

### 4.2 第二步：迁移文件

1. 将数据实体迁移到基础设施层：
   ```bash
   mv src/main/java/com/linkchat/entity/* src/main/java/com/linkchat/infrastructure/persistence/entity/
   ```

2. 将Mapper映射器迁移到基础设施层：
   ```bash
   mv src/main/java/com/linkchat/mapper/* src/main/java/com/linkchat/infrastructure/persistence/mapper/
   ```

3. 更新Mapper接口的package声明

4. 更新依赖Mapper的类的import语句

### 4.3 第三步：迁移Netty相关代码

1. 将Netty相关代码迁移到基础设施层：
   ```bash
   mv src/main/java/com/linkchat/netty/* src/main/java/com/linkchat/infrastructure/netty/
   ```

2. 更新Netty相关类的package声明

3. 更新依赖Netty的类的import语句

### 4.4 第四步：删除空目录

```bash
rm -rf src/main/java/com/linkchat/entity
rm -rf src/main/java/com/linkchat/mapper
rm -rf src/main/java/com/linkchat/netty
```
